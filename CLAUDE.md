# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## What this folder is

This repo is the website source and the **WEB** anchor (slug `WEB`): `.anchor` at the root, the anchor's pages under `doc/` (`WEB.md` is the anchor page; `MYWEB.md` holds dev and hosting notes; `Website.md` and `WSITE.md` are redirects). `doc/` and this file are listed in `_config.yml` `exclude:`, so they are **never published** — do not treat them as site content.

## Site

Jekyll site deployed to https://oblinger.github.io/ via GitHub Pages auto-build on push.

- **Engine:** Jekyll 4.4.x with `jekyll-theme-cayman` (see `_config.yml`, `Gemfile`)
- **Deploy:** `git push` triggers GitHub Pages build. No CI/CD config to maintain.

### Common commands

Run from the repo root:

```bash
# jekyll serve --livereload at http://localhost:4000/
just preview
# git add -A, commit "Update site", push (GH Pages builds)
just publish
# rebuild the Quarto papers in gitproj/DeliberativeCoherence/, publish
just publish-dcl
```

### Layouts — pick the right one

Two custom layouts in `_layouts/`:

- **`blank`** — minimal `<html>` shell. Used for hand-styled landing pages (`index.markdown`, `projects.markdown`, `elsewhere.markdown`) that embed their own `<head>` block with Source Sans Pro font and the site's signature teal (`#23ccbe`) link color. When editing or adding a top-level landing page, copy this inline `<head>` to keep the styling consistent.
- **`cayman`** — the default theme layout. Used for documentation pages like `gitproj/dans-anchor-system/index.md`.

### `gitproj/` — externally populated subdirectories

Several `gitproj/<project>/` directories are **generated by other repos**, not edited in place. Re-running their build overwrites the contents:

- `gitproj/HookAnchor/` — produced by `just docs-deploy` in the HookAnchor repo
- `abio-docs/` — produced by `just docs-deploy` in the alienbio repo
- `gitproj/DeliberativeCoherence/*.html` — Quarto-rendered from the `.qmd` sources via `just publish-dcl`
- `gitproj/dans-anchor-system/` — published by `git push` from `~/.claude/skills/`

Before editing any file under these paths, check whether it is sourced elsewhere — otherwise your edits will be lost on the next deploy.

`gitproj/AlienBiology/` and the standalone landing pages are edited in this repo directly.
